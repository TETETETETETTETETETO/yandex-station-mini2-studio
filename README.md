## 1. Аппаратная архитектура и драйверы

1. **Экран часов (Clock LED Display):**
   - Контроллер: чип **IS31FL3236** (36-канальный ШИМ LED-драйвер I2C).
   - Адрес на шине: `i2c-0` по адресу `0x3f` (`/sys/bus/i2c/devices/0-003f`).
   - Используются 34 канала, экспортированные в стандартную Linux подсистему sysfs:
     `/sys/class/leds/mini2:white:clock*`
   - Разрядность яркости: `0` .. `255`.

2. **Верхнее кольцо (RGB Ring):**
   - 6 RGB-светодиодов на шине `i2c-1` (`1-003c`), доступные через sysfs:
     `/sys/class/leds/mini2:red:ring1..6`
     `/sys/class/leds/mini2:green:ring1..6`
     `/sys/class/leds/mini2:blue:ring1..6`

## 2. Разбор файлов и директорий

### 2.1 `/system/vendor/quasar/ledconfigs/`
В папке находятся цветовые калибровочные профили (`blue.json`, `red.json`, а также ожидаемый системой `gray.json`):
- Содержимое: матрица преобразования цветового пространства 3x3 (`"type": "matrix"`).
- **Назначение**: компенсация оптического спектрального искажения света при прохождении через ткань корпуса разных цветов (синяя, красная, серая станция). Это калибровка RGB-кольца, чтобы при заданной команде (например, фиолетовый или бирюзовый) цвет выглядел одинаково вне зависимости от цвета тканевой оплетки.

### 2.2 `/system/vendor/quasar/ledpatterns/clock/`
Файлы системных анимаций экрана часов:
- `alice_listening.binscled.zst`
- `alice_speaking.binscled.zst`
- `alice_thinking.binscled.zst`
- `player_dislike.binscled.zst`
- `player_like.binscled.zst`
- `player_next_track.binscled.zst`
- `player_pause.binscled.zst`
- `player_previous_track.binscled.zst`
- `ringing.binscled.zst`

### 2.3 Формат сжатия: Zstandard с кастомным словарем
Файлы сжаты алгоритмом **Zstandard (.zst)**, но стандартный распаковщик без словаря выдает ошибку, так как использован предварительно обученный словарь `/system/vendor/quasar/zstd.dict` (49 152 байт).
Для распаковки в Python:
```python
import zstandard as zstd
with open("zstd.dict", "rb") as df:
    dict_data = zstd.ZstdCompressionDict(df.read())
dctx = zstd.ZstdDecompressor(dict_data=dict_data)
raw_animation = dctx.decompress(compressed_bytes, max_output_size=10*1024*1024)
```

### 2.4 Бинарный формат `.binscled` (Segment Clock LED)
После распаковки файл представляет собой плоский массив несжатых кадров фиксированной длины:
- **Размер одного кадра: ровно 35 байт.**
- **Байты 0..33 (34 байта)**: значения яркости (0–255) для каждого из 34 каналов светодиодов.
- **Байт 34 (1 байт)**: длительность текущего кадра в миллисекундах (обычно `20` мс = 50 FPS, либо `100` / `160` мс).

#### Раскладка каналов (stride = 7 сегментов на позицию):
1. **Позиция 0 (Цифра 1)** — каналы 0..6:
   `0: G1`, `1: A1`, `2: B1`, `3: C1`, `4: D1`, `5: E1`, `6: F1`
2. **Позиция 1 (Цифра 2)** — каналы 7..13:
   `7: G2`, `8: A2`, `9: B2`, `10: C2`, `11: D2`, `12: E2`, `13: F2`
3. **Позиция 2 (Символы двоеточия/плюса/минуса)** — каналы 14..20:
   `14: MINUS` (горизонтальная черта)
   `15: PLUS1` (верхняя точка двоеточия)
   `16: PLUS2` (нижняя точка двоеточия)
   `17: PLUS3`, `18: PLUS4`
4. **Позиция 3 (Цифра 3)** — каналы 21..27:
   `21: G3`, `22: A3`, `23: B3`, `24: C3`, `25: D3`, `26: E3`, `27: F3`
5. **Позиция 4 (Цифра 4 и значок градуса)** — каналы 28..33:
   `28: G4`, `29: A4`, `30: B4`, `31: DEGREE`, `32: C4`, `33: D4`

## 3. Топология 7-сегментных индикаторов

Каждая цифра (индексы 1..4) состоит из стандартных 7 сегментов:
```
       A
     +---+
   F |   | B
     +-G-+
   E |   | C
     +---+
       D
```
- Имена в sysfs: `mini2:white:clock{Segment}{DigitIndex}` (например, `clockA1`, `clockG4`).
- Разделитель (двоеточие): `clockPLUS1` (верхняя точка), `clockPLUS2` (нижняя точка).
- Знак минус: `clockMINUS`.
- Знак плюс: комбинация `clockPLUS1` + `clockPLUS2` + `clockMINUS`.
- Значок градуса: `clockDEGREE` (`°`).

## 4. Как выводить произвольные пиксели и текст

### Способ 1: Прямая запись в sysfs через ADB / локальный шелл
```bash
# 1. Погасить все сегменты экрана:
for l in /sys/class/leds/mini2:white:clock*; do echo 0 > $l/brightness; done

# 2. Зажечь отдельные сегменты (например, цифру '7' на первой позиции: A1, B1, C1):
echo 200 > /sys/class/leds/mini2:white:clockA1/brightness
echo 200 > /sys/class/leds/mini2:white:clockB1/brightness
echo 200 > /sys/class/leds/mini2:white:clockC1/brightness

# 3. Зажечь двоеточие (часы : минуты):
echo 150 > /sys/class/leds/mini2:white:clockPLUS1/brightness
echo 150 > /sys/class/leds/mini2:white:clockPLUS2/brightness

# 4. Зажечь значок градуса (°):
echo 150 > /sys/class/leds/mini2:white:clockDEGREE/brightness
```

### Способ 2: Веб-интерфейс «Alice Display Controller» (Интерактивный графический сервис)
Запуск интерактивного веб-сервиса (доступен в браузере на ПК или смартфоне):
```bash
python web_app.py
# или дважды кликните run_web_controller.bat
```
Откройте в браузере: **`http://localhost:8080`**

**Возможности веб-интерфейса:**
1. **Интерактивный экран часов**: нажимайте мышкой на любые сегменты (A, B, C, D, E, F, G всех 4 цифр, двоеточие, минус, градус) — они мгновенно загораются/гаснут на реальной колонке с нулевой задержкой через persistent ADB shell pipe.
2. **Автоматическая защита экрана от сброса часами**: при запуске и рисовании автоматически активируется режим блокировки часов (`killall -STOP maind`), чтобы фоновый процесс Алисы не затирал рисунок каждые 60 секунд. Переключатель режима доступен в шапке (зеленая кнопка «Защита экрана»).
3. **Индивидуальное управление каждым из 6 светодиодов кольца**:
   - Можно кликнуть на конкретный светодиод (1..6) и задать ему свой цвет через Color Picker или палитру.
   - Быстрые сочные градиенты: Радуга, Закат, Киберпанк, Аврора, Огонь.
   - Динамические эффекты кольца: Вращение (Spin), Дыхание (Pulse), Комета (Comet).
4. **Плавная регулировка яркости**: слайдер 0–255.
5. **Быстрый вывод текста**: поле ввода для мгновенного вывода текста/времени/температуры (`COOL`, `13:37`, `24°` и др.).
6. **Бегущая строка (Marquee)**: автоматический плавный скроллинг длинных фраз.
7. **Быстрые пресеты**: Like (❤️), Dislike (👎), Pause (⏸️), Play (▶️), Smile (😊), Bell (🔔), текущее время.
8. **Воспроизведение системных анимаций**: проигрывание официальных анимаций Яндекс Станции (`player_like`, `alice_speaking`, `ringing`, `player_pause` и др.).
9. **Студия анимаций (Кадры)**: покадровое сохранение нарисованных сегментов и воспроизведение собственной анимации.

### Способ 3: Использование консольного скрипта `led_controller.py`
В рабочей папке подготовлен скрипт `led_controller.py`:

```bash
# Вывести статичный текст (до 4 символов):
python led_controller.py text "COOL"
python led_controller.py text "13:37"
python led_controller.py text "24°"

# Бегущая строка (любой длины):
python led_controller.py scroll "HELLO ALICE HOW ARE YOU"

# Управление отдельными сегментами:
python led_controller.py raw "A1=255,B1=255,DEGREE=150,PLUS1=100"

# Воспроизведение анимации (.binscled или .binscled.zst):
python led_controller.py play player_like --loops 3
python led_controller.py play ringing

# Управление верхним RGB-кольцом:
python led_controller.py ring --color cyan
python led_controller.py ring --color red
python led_controller.py ring --off

# Очистить экран:
python led_controller.py clear
```

### Важное примечание о фоновом демоне Алисы (`platformd`)
Если стандартный процесс Яндекс Станции (`maind` / `platformd`) запущен, он обновляет текущее время раз в минуту (в начале каждой минуты) либо при вызове Алисы.
Если вам требуется постоянный монопольный вывод своего контента:
- Временно приостановить демон: `killall -STOP maind`
- Возобновить работу Алисы: `killall -CONT maind`
- Либо крутить цикл обновления в фоне вашего собственного скрипта.
